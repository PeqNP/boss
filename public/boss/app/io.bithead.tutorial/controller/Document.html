Document

A `UIDocument` window provides standardized behavior for managing "documents" (business models). The cancel, delete, and save operations provide the expected, boiler plate behavior, for each respective action. Cancel will ask the user if they want to cancel before closing, if the form is "dirty." Delete will ask the user if they really want to delete the model. And Save will display a message at the top providing direct feedback that the model was saved. It also disables the buttons when a document is being deleted or saved to prevent double-clicking.

In addition to this, the OS automatically sets the form as dirty when a form field changes its value.
